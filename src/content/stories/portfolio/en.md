This site has been my portfolio since 2018, and it has had five versions since. Each version stays online under its own address, and the version switcher moves between them, so the whole history can still be read the way it looked at the time.

### Five versions

- **2018, the original.** A single hand-written HTML page, the first time I put my work in one place.
- **2022, a reset.** Again one HTML page, starting over rather than patching the old one.
- **2023, the redesign.** The first version designed before it was built: I drew it in Figma, then built it with Next.js and React.
- **2024, a links page.** A deliberate step back to a minimal page that points to where my work lives.
- **2026, the rewrite.** The site you are on, rewritten in Astro as a static site.

### The designs behind it

The links on this page follow the design side of that history:

- **Personal Branding Logo**, on Behance and Dribbble, is the old logo that carried the earlier versions.
- **Eclipse Logo**, on Dribbble and Behance, is the logo that replaced it.
- **Portfolio**, on Behance, Dribbble and Figma, is the 2023 redesign, with the Figma file it was built from.
- **Portfolio Redesigns**, on Behance and Dribbble, gathers the designs I iterated on to reach how the site looks now.

### What the current version does

It lists my projects, public and private, with a case study for the ones that need one, along with my writings, my CV and a now page. It speaks seven languages, Arabic and Moroccan Arabic right to left among them, and falls back to English where a text has no translation. The details of public repositories come from GitHub at build time, with a saved copy for when GitHub is out of reach.

### The stack

Astro and TypeScript, built to static files and served at ouss.es. Its lint rules come from dx, my own ESLint config.
